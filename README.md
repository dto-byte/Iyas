# إياس

لعبة تدريب وتحدٍّ ذهني عربية بالكامل — تعمل في المتصفح، بلا خادم ولا حساب، وتُثبَّت على الهاتف وتعمل بلا إنترنت.

**العب الآن:** _(يُضاف الرابط بعد أول نشر)_

## ما فيها

خمسة عوالم، وفي كل عالم قوالب تحدٍّ تُولَّد آليًا فلا تتكرر الجولة مرتين:

| العالم | القوالب | ما يدرّبه |
|---|---|---|
| الملاحظة | ١٠ | الانتباه للتفاصيل الدقيقة وسرعة المسح البصري |
| الذاكرة | ١٠ | تذكّر المواضع والترتيب والمسارات بعد الإخفاء |
| المنطق | ١٠ | الاستدلال والاستنتاج من قاعدة أو دليل |
| الأنماط | ٩ | إدراك البنية والتناظر والتكرار البصري |
| التركيز | ٧ | مقاومة التداخل وكفّ الاستجابة التلقائية |

وتبقى سبعة عوالم قيد البناء: سرعة الاستجابة، التخطيط، الإدراك المكاني، التوقع، الفوضى، الوهم، الاحتراف.

## لماذا قد تختلف عن غيرها

- **عربية خالصة**: لا كلمة لاتينية واحدة تظهر للاعب، وكل الأرقام عربية شرقية، والواجهة من اليمين لليسار.
  وللغة طبقة خاصة في المحرك تضبط مطابقة الجنس والمعدود، فلا تقرأ "المربع الغريبة" ولا "١٧ جلسات".
- **كل تحدٍّ مولَّد ومُدقَّق**: يمرّ كل لغز على مدقّق يتحقّق أن له حلًّا واحدًا فقط قبل عرضه، ويُعاد
  توليده إن فشل. ويعتمد كل شيء على بذرة عشوائية فيمكن إعادة إنتاج أي جولة بالضبط.
- **صعوبة تتكيّف في الاتجاهين**: تنخفض مع تكرار الخطأ، وترتفع مع الإتقان — بشرط السرعة لا الصحّة
  وحدها، فمن يجيب صحيحًا في آخر لحظة لا يُرفع مستواه.
- **إتاحة حقيقية**: وضع لعمى الألوان بلوحة Okabe-Ito، ووضع لتقليل الحركة يستبعد القوالب التي
  تعتمد على الحركة جوهريًا، وحدّ أدنى ٤٤ بكسل لكل عنصر يُلمس.
- **سجلّ تقدّم**: سلسلة أيام، وخريطة نشاط، ومنحنى دقة لكل عالم. البيانات في متصفحك وحده.

## التشغيل محليًا

اللعبة ملفات ساكنة في `src/` — أي خادم ساكن يكفي:

```bash
node tests/serve.js
```

ثم افتح `http://localhost:8131`.

> فتح `src/index.html` مباشرة عبر `file://` لا ينفّذ السكربتات الخارجية في بعض البيئات، ولا يعمل
> فيه عامل الخدمة (يتطلّب `https` أو `localhost`).

## الاختبارات

سبع حزم اختبار تعمل في `jsdom`، وأي قالب أو عالم جديد يجب أن يمرّ عليها كلها قبل الاعتماد.
التفاصيل في [`tests/README.md`](tests/README.md).

```bash
cd tests && npm init -y && npm i jsdom
node session.js ../src     # يلعب جلسة كاملة في كل عالم × ٤ مستويات
node stress.js ../src 150  # ٢٧٦٠٠ محاولة توليد وتدقيق
node lang.js ../src 120    # فحص عربي لكل نص يراه اللاعب
```
